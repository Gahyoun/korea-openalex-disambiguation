# 동일인물 판정 방법론

## 1. 분석 단위와 전제

판정 단위는 `(professor_uid, OpenAlex work_id)`입니다. OpenAlex author ID와 ORCID는 관측값이지 정답 레이블이 아닙니다. 특히 흔한 동아시아 이름의 경우 한 author ID에 여러 연구자가 합쳐질 수 있으므로, 교수 이력에서 독립적으로 확인된 박사기관·박사연도·학과와 논문 연결망을 기준점으로 사용합니다.

## 2. 검증 seed와 진짜 데뷔연도

1. 박사연도 `Y`가 있으면 `[Y-5, Y]`를 박사 논문 탐색 구간으로 둡니다.
2. 이 구간에서 박사기관과 일치하는 논문을 찾습니다.
3. 기관명만 같은 것은 부족합니다. raw affiliation의 학과/연구단위가 교수의 기초분야와 맞거나, 학과가 누락된 경우 OpenAlex field가 허용 분야여야 합니다.
4. 가장 이른 해의 적격 논문을 seed로 정합니다. 같은 해에 공저자·기관·매우 가까운 주제로 연결된 논문도 seed cluster에 넣습니다.
5. 박사기관 seed가 없으면 분야 적합 prior-keep 논문으로 fallback하지만, 이 seed는 미검증으로 표시하며 후속 고립 논문을 자동 삭제하는 근거로 쓰지 않습니다.

이 규칙은 “같은 대학” 오류를 막습니다. 예를 들어 박사기관이 KAIST라도 물리학과 네트워크 논문은 seed가 될 수 있지만 기계공학과 신뢰성 논문은 seed가 될 수 없습니다.

## 3. 네 가지 독립 연결 증거

각 후보 논문에 대해 다음을 계산합니다.

1. **핵심 공저자 연결**: seed 공저자와 직접 겹치는가.
2. **기관 연결**: 박사기관 또는 검증된 재직기관과 일치하고 학과/분야도 모순되지 않는가.
3. **주제 거리**: 제목, OpenAlex topic/subfield/field/domain으로 만든 sparse TF-IDF 벡터와 seed centroid의 cosine similarity.
4. **논문군 경로**: 공저자, 분야가 맞는 기관, 동일 topic+시간 근접, 매우 높은 텍스트 유사도로 만든 그래프에서 seed에 도달하는가.

TF-IDF는 실행할 때 해당 교수의 전체 논문 집합에서 결정적으로 계산합니다. 외부 임베딩 API를 호출하지 않아 같은 입력·설정이면 같은 결과가 나옵니다.

## 4. 전공 간 거리 처리

분야 허용 목록은 `config/default.json`에 둡니다. 물리의 수학·컴퓨터과학, 수학의 물리·컴퓨터과학, 화학의 재료·생화학, 생물의 의학·환경·화학 등 자연스러운 확장은 허용합니다.

단순 분야 이름만으로 삭제하지는 않습니다. 네트워크과학에서 건축/건설 논문처럼 주제도 멀고, 핵심 공저자도 없고, 기관·학과도 연결되지 않으며, seed graph 경로도 없을 때 강한 동명이인 신호가 됩니다. 반대로 이산수학↔네트워크과학, 생태계 동역학 모델링↔수리생물학은 주제 또는 graph 연결이 있어 보존될 수 있습니다.

## 5. confidence와 자동 행동

### high namesake → 자동 drop 후보

- 박사 취득 5년보다 이전인 논문, 또는
- 검증된 박사기관 seed보다 이르면서 모든 연결이 없는 논문, 또는
- 검증 seed가 있고 공저자·기관·주제·graph 연결이 모두 없으며 학과/분야 충돌까지 있는 논문.

### medium/low namesake → review

고립되었지만 학과 데이터가 없거나, seed가 fallback이거나, 주제 거리가 경계값인 경우입니다. 원본에서 삭제하지 않고 2차 판정 대상으로 둡니다.

### high/medium true → keep

seed 자체이거나, graph 경로와 공저자/기관 중 하나가 함께 있거나, 독립 양성 증거가 둘 이상인 경우입니다.

### low true → review

일부 연속성은 있으나 자동 보존하기에 증거가 약한 경우입니다.

## 6. ORCID 규칙

ORCID exact는 `+1` 보조 점수일 뿐입니다. 공저자·기관·주제·graph 중 독립 연결이 하나도 없으면 `orcid_only=true`가 되며 ORCID 때문에 자동 keep되지 않습니다. 이는 잘못 합쳐진 OpenAlex 저자 레코드에 ORCID가 전파되는 상황을 방어합니다.

## 7. 연구년·겸임·복수 소속

논문 identity와 career employment는 분리합니다. 서로 가까운 우편번호의 대학·연구소 동시 소속, 연구년 방문기관, 겸임기관은 공저자/논문군 연속성이 있으면 삭제 사유가 아닙니다. 이 라이브러리는 논문을 판정하며 재직 이력을 단독으로 삭제하지 않습니다.

## 8. 2차 CLI 판정

1차 review만 외부 CLI로 보낼 수 있습니다. payload에는 실명과 ORCID를 넣지 않고 교수 해시 토큰, 분야, 박사기간, 검증 seed 제목, 후보 제목·topic, 네 가지 증거와 1차 이유를 담습니다.

- 단일 provider: `high`만 review 해소에 사용하고 최종 confidence는 `medium`으로 제한합니다.
- 복수 provider: 다수결을 사용합니다. 다수 판단이 모두 medium 이상이면 최종 `high`가 될 수 있습니다.
- 동률/충돌: review 유지.

## 9. 재현성과 감사

- 입력 DB SHA-256, 라이브러리 버전, 설정 전체, 실행 시각을 manifest에 저장합니다.
- 각 논문에는 점수뿐 아니라 원인 코드 배열을 저장합니다.
- 진짜 논문, 동명이인 논문, review를 각각 JSONL로 저장합니다.
- 원본 DB를 직접 지우지 않고 overlay DB에서 최종 행동을 관리합니다.
- 설정 임계값을 바꾸면 새 output 디렉터리에 다시 실행해 전후 결과를 비교합니다.

## 10. 한계

raw affiliation의 학과가 없고 topic도 부정확한 단독 논문, 이름이 같은 두 연구자가 같은 기관·유사 분야에 있었던 경우, 경력 초기에 공저자 단절이 큰 분야 전환은 자동 판정 한계입니다. 이런 사례는 confidence를 낮추고 review로 남기는 것이 기본 정책입니다.
